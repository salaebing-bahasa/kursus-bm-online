## Objektif Pembelajaran

Pada akhir sesi, peserta dapat:

- Menyebut dan menulis sekurang-kurangnya **15 ungkapan salam dan sapaan** dengan sebutan yang betul
- Membezakan penggunaan salam mengikut agama, masa, dan situasi (formal / tidak formal)
- Memperkenalkan diri: nama, asal usul, pekerjaan, dan maklumat peribadi asas
- Menjalankan perbualan perkenalan diri (5–7 ayat) bersama rakan secara dalam talian
- Menulis perenggan pendek (5 ayat) memperkenalkan diri sendiri

## Perbualan

### Dialog 1 — Bertemu Kali Pertama (Tidak Formal)

*Situasi: Farid dan Nurul bertemu dalam kelas dalam talian buat kali pertama.*

| Penutur | Dialog |
|---|---|
| Farid | Assalamualaikum! Saya Farid. Awak siapa? |
| Nurul | Waalaikumsalam! Saya Nurul. Seronok bertemu dengan awak, Farid. |
| Farid | Seronok bertemu dengan awak juga. Awak berasal dari mana, Nurul? |
| Nurul | Saya berasal dari Pattani. Awak pula? |
| Farid | Saya dari Songkhla. Awak belajar di mana sekarang? |
| Nurul | Saya belajar di Universiti Thaksin. Awak juga? |
| Farid | Ya, saya juga. Kita sekampus rupanya! Umur awak berapa, kalau boleh tahu? |
| Nurul | Saya 22 tahun. Awak? |
| Farid | Saya 23 tahun. Apa pekerjaan awak selain belajar? |
| Nurul | Saya bekerja sambilan sebagai guru tuisyen. Semoga kita boleh belajar bersama-sama! |

### Dialog 2 — Perkenalan Diri dalam Situasi Formal

*Situasi: Dalam mesyuarat dalam talian, Ahmad memperkenalkan dirinya.*

| Penutur | Dialog |
| --- | --- |
| Pengerusi | Selamat datang semua. Marilah kita mulakan dengan sesi perkenalan diri. Encik Ahmad, sila mulakan. |
| Ahmad | Terima kasih, Encik Pengerusi. Assalamualaikum dan selamat petang. Nama saya Ahmad bin Rashid. Saya berasal dari Hatyai, Songkhla, Thailand. Saya berumur 30 tahun dan saya bekerja sebagai pentadbir di Universiti Thaksin. Saya mengambil kursus Bahasa Melayu ini untuk meningkatkan kemahiran komunikasi saya dengan rakan-rakan dari Malaysia. Sekian, terima kasih. |
| Pengerusi | Terima kasih, Encik Ahmad. Perkenalan yang sangat baik! |

## Tatabahasa

### Ayat Penyata — Memperkenalkan Diri

**Struktur: SUBJEK + ialah / adalah + PREDIKAT**

| Subjek | Pemeri | Predikat | Ayat Lengkap |
|---|---|---|---|
| Nama saya | ialah | Ahmad bin Rashid | Nama saya ialah Ahmad bin Rashid. |
| Pekerjaan saya | ialah | guru Bahasa Melayu | Pekerjaan saya ialah guru Bahasa Melayu. |
| Hobi saya | ialah | membaca dan melukis | Hobi saya ialah membaca dan melukis. |

> **Nota:** *ialah* digunakan di hadapan frasa nama, manakala *adalah* digunakan di hadapan frasa adjektif dan frasa sendi nama.

### Kata Tanya untuk Perkenalan

| Kata Tanya | Contoh Soalan | Contoh Jawapan |
|---|---|---|
| Siapa | Awak siapa? | Saya Nurul. |
| Apa | Apa nama awak? | Nama saya Farid. |
| Berapa | Berapa umur awak? | Saya 24 tahun. |
| Dari mana | Awak dari mana? | Saya dari Kelantan. |
| Di mana | Di mana awak tinggal sekarang? | Saya tinggal di Hatyai. |
| Apa kerja | Apa kerja awak? | Saya bekerja sebagai jurutera. |
| Bila | Bila awak mula belajar BM? | Saya mula belajar bulan lalu. |

### Saya, Aku dan Anda

| Kata Ganti | Bila Digunakan | Contoh | Tahap |
| --- | --- | --- | --- |
| saya | Semua situasi | Saya berasal dari Thailand. | Neutral |
| aku | Rakan sebaya | Aku nak pergi makan dulu. | Tidak formal |
| anda | Penulisan formal, iklan, ucapan | Anda dijemput hadir ke majlis ini. | Sangat formal |
