## Objektif Pembelajaran

Pada akhir sesi, peserta dapat:

- Menyebut dan menulis **nombor kardinal** 0 – 1,000,000 dalam Bahasa Melayu
- Menyebut dan menulis **nombor ordinal** (pertama, kedua, ketiga …) dengan betul
- Membaca dan menyatakan **waktu** menggunakan jam, minit, dan ungkapan waktu
- Menggunakan kata tanya *Pukul berapa?, Berapa?* dan *Bilakah?* dalam perbualan
- Menyusun jadual harian dan menerangkannya dalam Bahasa Melayu

## Perbualan

### Dialog 1 — Bertanya tentang Masa

| Penutur | Dialog |
|---|---|
| Amir | Assalamualaikum, Nurul. Pukul berapa kelas Bahasa Melayu kita hari ini? |
| Nurul | Waalaikumsalam, Amir. Kelas kita bermula pukul sembilan pagi dan tamat pukul sepuluh setengah. |
| Amir | Oh, masih ada masa lagi. Sekarang baru pukul lapan lima belas pagi. |
| Nurul | Ya. Kelas bermula dalam masa empat puluh lima minit lagi. |
| Amir | Baiklah. Hari ini hari apa ya? |
| Nurul | Hari ini hari Rabu, dua puluh tiga April. |
| Amir | Terima kasih, Nurul. Jumpa nanti dalam kelas! |

### Dialog 2 — Jadual Harian

| Penutur | Dialog |
|---|---|
| Hafiz | Suria, boleh ceritakan jadual harian awak? |
| Suria | Boleh! Setiap pagi, saya bangun pada pukul lima setengah. Saya solat dan kemudian bersarapan pada pukul enam lebih. |
| Hafiz | Wah, awal sekali! Pukul berapa awak pergi ke pejabat? |
| Suria | Saya bertolak dari rumah pada pukul tujuh empat puluh lima dan sampai di pejabat kira-kira pukul lapan. |
| Hafiz | Berapa lama awak bekerja? |
| Suria | Saya bekerja dari pukul lapan pagi hingga pukul lima petang, termasuk rehat tengah hari satu jam. |
| Hafiz | Pada waktu malam pula? |
| Suria | Pada waktu malam, saya belajar dalam talian dari pukul lapan hingga pukul sepuluh. Kemudian saya tidur pukul sebelas. |

### Dialog 3 — Membuat Temu Janji

| Penutur | Dialog |
|---|---|
| Rizwan | Selamat pagi. Saya ingin membuat temu janji dengan Doktor Halim. |
| Penyambut tetamu | Selamat pagi. Doktor ada pada hari Khamis, pukul dua hingga pukul empat petang. |
| Rizwan | Khamis yang akan datang? Tarikh berapa? |
| Penyambut tetamu | Khamis, dua puluh lapan April. Encik mahu pukul berapa? |
| Rizwan | Saya mahu pukul tiga petang kalau boleh. |
| Penyambut tetamu | Baiklah. Sila datang pada pukul dua empat puluh lima untuk pendaftaran. |

## Tatabahasa

### Pembentukan Nombor

| Pola | Rumus | Contoh |
|---|---|---|
| Belasan (13–19) | tiga / empat ... + belas | 13 = tiga belas |
| Puluhan (20–90) | dua / tiga ... + puluh | 50 = lima puluh |
| Puluhan + unit | puluhan + unit | 35 = tiga puluh lima |
| Ratus | se / dua ... + ratus | 250 = dua ratus lima puluh |
| Ribu | se / dua ... + ribu | 1,500 = seribu lima ratus |
| **Khas** | 11 = *sebelas*, 100 = *seratus*, 1,000 = *seribu* | bukan "satu belas", "satu ratus" |

### Membaca Waktu

| Masa | Gaya Formal | Gaya Perbualan |
|---|---|---|
| 1:00 | pukul satu | pukul satu |
| 1:15 | pukul satu lima belas | pukul satu suku |
| 1:30 | pukul satu tiga puluh | pukul satu setengah |
| 1:45 | pukul satu empat puluh lima | pukul dua kurang suku |
| 7:00 pagi | pukul tujuh pagi | pukul tujuh pagi |
| 12:00 | pukul dua belas tengah hari | tengah hari |
| 8:00 malam | pukul lapan malam | pukul lapan malam |

### Kata Tanya untuk Nombor dan Masa

| Kata Tanya | Contoh Soalan | Contoh Jawapan |
|---|---|---|
| Berapa? | Berapa harga buku itu? | Harganya dua puluh lima ringgit. |
| Berapa lama? | Berapa lama perjalanan ke KL? | Lebih kurang empat jam. |
| Pukul berapa? | Pukul berapa kedai dibuka? | Kedai dibuka pukul lapan pagi. |
| Tarikh berapa? | Tarikh berapa mesyuarat itu? | Pada lima belas Mei. |
| Hari apa? | Hari apa ujian kita? | Ujian pada hari Jumaat. |
| Bilakah? | Bilakah program itu bermula? | Program bermula bulan Jun. |

### Pada, Dalam, Selama, Sejak

| Kata | Kegunaan | Contoh |
|---|---|---|
| pada | Masa tertentu | Saya tiba pada pukul tiga petang. |
| dalam | Tempoh akan datang | Tugasan mesti dihantar dalam masa dua jam. |
| selama | Tempoh berlaku | Kami belajar selama tiga jam. |
| sejak | Dari dulu hingga kini | Dia tinggal di sini sejak tahun 2010. |

### Penjodoh Bilangan Asas

| Penjodoh | Untuk | Contoh |
|---|---|---|
| orang | manusia | tiga **orang** pelajar |
| buah | benda besar / umum | dua **buah** rumah |
| biji | benda kecil bulat | lima **biji** telur |
| ekor | haiwan | seekor kucing |
