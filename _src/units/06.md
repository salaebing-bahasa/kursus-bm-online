## Objektif Pembelajaran

Pada akhir sesi, peserta dapat:

- Menyebut dan menulis sekurang-kurangnya **25 kosa kata** bilik, perabot, dan persekitaran rumah
- Menghuraikan lokasi objek dengan **kata sendi nama tempat**: di atas, di bawah, di dalam, di luar, di sebelah, di hadapan, di belakang
- Menggunakan **kata adjektif** (bersih, luas, selesa, cantik) untuk memerihalkan rumah
- Menjalankan perbualan pendek (4–6 ayat) tentang rumah dengan rakan
- Menulis sekurang-kurangnya 4 ayat menghuraikan rumah sendiri

## Perbualan

### Dialog 1 — Rumah Saya

| Penutur | Dialog |
|---|---|
| Razman | Assalamualaikum, Sara. Awak tinggal di mana? |
| Sara | Waalaikumsalam. Saya tinggal di Songkhla, dalam sebuah rumah teres dua tingkat. Awak pula? |
| Razman | Saya tinggal di pangsapuri di bandar. Rumah awak ada berapa bilik? |
| Sara | Rumah saya ada tiga bilik tidur, dua bilik air, sebuah dapur, dan sebuah ruang tamu. |
| Razman | Wah, besarnya! Di mana bilik awak? |
| Sara | Bilik saya di tingkat atas, di sebelah bilik ibu bapa saya. Ada tingkap besar menghadap taman. |
| Razman | Perabot apa yang ada di bilik awak? |
| Sara | Ada katil, almari, meja belajar, dan penghawa dingin. Saya suka bilik saya kerana selesa. |

### Dialog 2 — Melawat Rumah Baharu

| Penutur | Dialog |
|---|---|
| Hakim | Nadia, saya baru berpindah ke rumah baharu minggu lepas. Mahu datang melawat? |
| Nadia | Oh, bagus! Rumah baharu di mana? |
| Hakim | Di Taman Sri Damai, tidak jauh dari sekolah. Lebih kurang lima minit sahaja. |
| Nadia | Jenis rumah apa? Rumah teres atau banglo? |
| Hakim | Rumah banglo. Ada halaman depan dan belakang. Di halaman belakang ada pokok buah-buahan. |

| Nadia | Baiklah! Saya akan datang pukul sepuluh pagi. Terima kasih atas jemputan! |

## Tatabahasa

### Ayat Lokasi

**Struktur: SUBJEK + ada / terletak / berada + KATA SENDI NAMA + TEMPAT**

| Subjek | Kata Kerja | Kata Sendi | Tempat | Ayat |
|---|---|---|---|---|
| Buku | ada | di atas | meja | Buku ada di atas meja. |
| Katil | berada | di dalam | bilik tidur | Katil berada di dalam bilik tidur. |
| Televisyen | ada | di hadapan | sofa | Televisyen ada di hadapan sofa. |
| Taman | terletak | di belakang | rumah | Taman terletak di belakang rumah. |

### Ada, Mempunyai, Terdapat

| Kata | Penggunaan | Contoh |
| --- | --- | --- |
| ada | Kewujudan | Di ruang tamu ada sofa besar. |
| mempunyai | Pemilikan | Rumah saya mempunyai tiga bilik tidur. |
| terdapat | Formal | Terdapat sebuah taman di belakang rumah. |

### Kata Adjektif untuk Rumah

**Struktur: [Subjek] + [Kata Adjektif]** → *Bilik saya selesa.*

| Kata Adjektif | Contoh |
| --- | --- |
| besar / kecil | Bilik saya kecil tetapi selesa. |
| luas / sempit | Ruang tamu kami sangat luas. |
| selesa | Katil saya sangat selesa. |
| bersih | Dapur rumah saya sangat bersih. |
| kemas | Bilik adik saya sentiasa kemas. |
| baharu / lama | Rumah nenek sudah lama tetapi kukuh. |
| cantik | Taman di luar rumah itu cantik. |
| jauh / dekat | Rumah saya dekat dengan sekolah. |

### Penjodoh Bilangan dalam Konteks Rumah

| Penjodoh | Contoh |
|---|---|
| buah | Kami mempunyai **sebuah** rumah teres. Ada empat **buah** kerusi. |
| batang | Ada dua **batang** pokok kelapa di halaman. |
| tingkat | Rumah kami ada dua **tingkat**. |
