## Objektif Pembelajaran

Pada akhir sesi, peserta dapat:

- Menyebut dan menulis sekurang-kurangnya **25 kosa kata** rutin harian dengan sebutan yang tepat
- Menyatakan masa dengan betul (pagi, tengah hari, petang, malam)
- Membina ayat **Subjek + Kata Kerja + Objek** (Saya makan nasi.)
- Menyusun urutan aktiviti dengan penanda wacana: *mula-mula, kemudian, selepas itu, akhir sekali*
- Menulis satu perenggan (5 ayat) tentang rutin harian sendiri

## Kosa Kata

|---|---|---|
| subuh | รุ่งเช้า (ก่อนฟ้าสาง) | Ayah solat subuh setiap hari. |
| pagi | ตอนเช้า | Saya bangun tidur pada waktu pagi. |
| tengah hari | เที่ยงวัน | Kami makan tengah hari bersama-sama. |
| petang | ตอนบ่าย / เย็น | Dia bersenam pada waktu petang. |
| malam | ตอนกลางคืน | Saya belajar pada waktu malam. |
| lewat malam | ดึก | Jangan tidur terlalu lewat malam. |

| sejam | หนึ่งชั่วโมง | Dia belajar selama sejam setiap malam. |

## Perbualan

### Dialog 1 — Rutin Harian

| Penutur | Dialog |
|---|---|
| Farid | Assalamualaikum, Hana! Apa khabar hari ini? |
| Hana | Waalaikumsalam! Khabar baik, alhamdulillah. Farid, pukul berapa awak bangun tidur setiap hari? |
| Farid | Saya biasanya bangun pada pukul lima setengah pagi. Kemudian saya bersolat subuh. |
| Hana | Wah, awal sekali! Saya bangun pukul enam. Selepas mandi, saya bersarapan bersama keluarga. |
| Farid | Pukul berapa awak pergi ke kelas? |
| Hana | Kelas dalam talian saya bermula pukul lapan pagi dan berakhir pukul dua belas tengah hari. |
| Farid | Selepas kelas, apa yang awak buat? |
| Hana | Saya makan tengah hari, kemudian berehat sebentar. Pada waktu petang, saya bersenam. |
| Farid | Malam pula? |
| Hana | Pada waktu malam saya mengulang kaji selama sejam, menonton televisyen, dan tidur sebelum pukul sebelas. |

### Dialog 2 — Hari Bekerja dan Hujung Minggu

| Penutur | Dialog |
|---|---|
| Guru | Rashid, adakah rutin harian awak pada hari bekerja berbeza dengan hujung minggu? |
| Rashid | Ya, cikgu. Pada hari bekerja, saya bangun pukul enam pagi. Pada hujung minggu, saya bangun lewat sedikit, kira-kira pukul tujuh. |
| Guru | Apa yang awak buat pada hujung minggu? |
| Rashid | Saya membantu ibu membersihkan rumah. Selepas itu, kami sekeluarga pergi membeli-belah atau berjalan-jalan di taman. |
| Guru | Bagus! Awak pandai menguruskan masa. |

## Tatabahasa

### Struktur Ayat Asas

| Struktur | Contoh |
|---|---|
| Subjek + Kata Kerja | Saya **mandi**. |
| Subjek + Kata Kerja + Objek | Saya **makan nasi**. |
| Subjek + Kata Kerja + Keterangan Masa | Saya **bangun** pada pukul enam pagi. |

### Kata Kerja Transitif

Kata kerja **transitif** memerlukan **objek** selepasnya.

| Ayat | Kata Kerja | Objek |
|---|---|---|
| Ibu memasak **sarapan**. | memasak | sarapan |
| Saya membaca **buku**. | membaca | buku |
| Dia menggosok **gigi**. | menggosok | gigi |
| Kami menonton **televisyen**. | menonton | televisyen |

### Penanda Wacana Urutan

| Penanda | Bahasa Thai | Contoh |
|---|---|---|
| Mula-mula | ตอนแรก | Mula-mula, saya bangun tidur. |
| Kemudian | จากนั้น | Kemudian, saya mandi. |
| Selepas itu | หลังจากนั้น | Selepas itu, saya bersolat. |
| Akhir sekali | สุดท้าย | Akhir sekali, saya pergi ke kelas. |
| Semasa / ketika | ขณะที่ | Semasa makan malam, kami berbual. |

## Latihan

### Latihan A — Padankan Aktiviti dengan Waktu

| Aktiviti | Waktu |
|---|---|
| 1. menggosok gigi dan mandi | A. 10:00 malam |
| 2. makan tengah hari | B. 6:00 pagi |
| 3. mengulang kaji pelajaran | C. 12:30 tengah hari |
| 4. bangun tidur | D. 8:00 malam |
| 5. tidur | E. 6:30 pagi |

### Latihan B — Lengkapkan Ayat

*[ kemudian · selepas · sebelum · biasanya · pada pukul · selama ]*

1. Saya bangun tidur ________ enam pagi setiap hari.
2. ________ mandi, saya bersarapan bersama keluarga.
3. Dia ________ tidur awal, sekitar pukul sepuluh malam.
4. Ibu memasak sarapan, ________ menghantar adik ke sekolah.
5. Saya bersenam ________ tiga puluh minit setiap petang.
6. Saya menggosok gigi ________ tidur.

### Latihan C — Rantai Rutin

Sambung ayat rakan: *"Mula-mula, saya bangun tidur." → "Kemudian, saya ..." → "Selepas itu, saya ..."*
