## Objektif Pembelajaran

Pada akhir sesi, peserta dapat:

- Menyebut dan menulis sekurang-kurangnya **25 kosa kata** arah dan lokasi dengan tepat
- Bertanya dan menjawab tentang arah dengan *Di mana, Bagaimana cara ke,* dan *Berapa jauh*
- Menggunakan **kata sendi nama** *di, ke,* dan *dari* dengan betul
- Memberi arahan jalan yang lengkap: *belok kanan, jalan terus, ambil jalan ...*
- Menjalankan perbualan pendek (5–7 ayat) tentang cara pergi ke sesuatu tempat

## Perbualan

### Dialog 1 — Bertanya Arah ke Hospital

*Situasi: Encik Razif, seorang pelancong, bertanya arah kepada Puan Laila di tepi jalan.*

| Penutur | Dialog |
|---|---|
| Razif | Maaf, boleh saya tanya? Di mana hospital yang berhampiran? |
| Laila | Boleh. Hospital itu tidak jauh dari sini. Jalan terus sahaja. |
| Razif | Jalan terus ke mana? |
| Laila | Jalan terus hingga ke simpang lampu isyarat. Kemudian belok kiri. |
| Razif | Belok kiri di lampu isyarat. Kemudian? |
| Laila | Selepas belok kiri, jalan lebih kurang 200 meter. Hospital di sebelah kanan, berhadapan dengan taman awam. |
| Razif | Berapa jauh dari sini? |
| Laila | Lebih kurang lima minit berjalan kaki sahaja. |
| Razif | Terima kasih banyak-banyak, Puan. |
| Laila | Sama-sama. Semoga selamat sampai. |

### Dialog 2 — Ke Pusat Membeli-belah

| Penutur | Dialog |
|---|---|
| Siti | Encik, maaf mengganggu. Bagaimana cara ke Pusat Membeli-belah Angsana dari sini? |
| Ahmad | Tidak jauh. Pertama, ikut jalan besar ini ke arah utara. |
| Siti | Jalan besar yang ini? |
| Ahmad | Ya, betul. Kemudian, di simpang pertama, belok kanan. Awak akan nampak stesen minyak di sudut simpang itu. |
| Siti | Belok kanan di simpang pertama, ada stesen minyak. Faham. Selepas itu? |
| Ahmad | Selepas stesen minyak, jalan terus lebih kurang 300 meter. Pusat membeli-belah itu di sebelah kiri. Bangunannya besar dan berwarna biru. |
| Siti | Boleh pergi dengan berjalan kaki? |
| Ahmad | Boleh, lebih kurang sepuluh minit. Atau awak boleh naik teksi. |
| Siti | Baiklah, saya berjalan kaki sahaja. Terima kasih, Encik! |

## Tatabahasa

### Ayat Perintah (Arahan Jalan)

**Struktur: KATA KERJA + KETERANGAN (tanpa subjek)**

| Kata Kerja | Keterangan | Ayat Arahan |
|---|---|---|
| Jalan | terus hingga ke hujung jalan | Jalan terus hingga ke hujung jalan. |
| Belok | kanan di simpang pertama | Belok kanan di simpang pertama. |
| Ambil | jalan kedua di sebelah kiri | Ambil jalan kedua di sebelah kiri. |
| Naik | lif ke tingkat tiga | Naik lif ke tingkat tiga. |
| Seberang | jalan di lintasan pejalan kaki | Seberang jalan di lintasan pejalan kaki. |
| Berhenti | di hadapan masjid | Berhenti di hadapan masjid. |

### Di, Ke, Dari

| Kata Sendi | Kegunaan | ✓ Betul | ✗ Salah |
|---|---|---|---|
| di | Kedudukan tetap | Ayah ada **di** rumah. | Ayah ada ke rumah. |
| ke | Pergerakan / tujuan | Mari pergi **ke** kedai makan. | Mari pergi di kedai makan. |
| dari | Tempat asal | Saya datang **dari** sekolah. | Saya datang di sekolah. |

> **Ingat:** *Ke* untuk pergerakan, *di* untuk kedudukan tetap. Jangan gunakan satu kata sendi untuk semua maksud.

### Kata Tanya Arah

| Kata Tanya | Contoh Soalan | Contoh Jawapan |
|---|---|---|
| Di mana | Di mana hospital yang berhampiran? | Di hujung jalan ini. |
| Ke mana | Ke mana Encik hendak pergi? | Saya hendak ke pasar malam. |
| Dari mana | Dari mana awak datang? | Saya datang dari stesen bas. |
| Bagaimana | Bagaimana saya hendak pergi ke hospital? | Naik teksi dari sini. |
| Berapa jauh | Berapa jauh dari sini ke masjid? | Lebih kurang 500 meter. |
| Berapa lama | Berapa lama untuk sampai? | Lebih kurang 15 minit. |

### Penanda Wacana dalam Arahan

| Penanda | Contoh |
| --- | --- |
| pertama | Pertama, jalan terus ke simpang. |
| kemudian | Kemudian, belok kiri di lampu isyarat. |
| selepas itu | Selepas itu, jalan lebih kurang 100 meter. |
| akhirnya | Akhirnya, awak akan sampai di hotel itu. |
| hingga | Jalan terus hingga ke hujung jalan. |
