## Objektif Pembelajaran

Pada akhir sesi, peserta dapat:

- Menyebut dan menulis sekurang-kurangnya **25 kosa kata** kesihatan diri dan anggota badan
- Menghuraikan gejala penyakit biasa dengan ayat yang gramatis
- Menggunakan **kata hubung** (*dan, atau, tetapi, kerana*) untuk membina ayat yang lebih panjang
- Membina dialog antara pesakit dan doktor dengan sopan
- Menulis mesej ringkas kepada majikan / guru untuk memohon cuti sakit

## Perbualan

### Dialog 1 — Di Klinik

| Penutur | Dialog |
|---|---|
| Jururawat | Selamat pagi. Ada apa yang boleh saya bantu? |
| Amir | Selamat pagi. Saya ingin berjumpa doktor. Saya rasa kurang sihat. |
| Jururawat | Apa masalah encik? |
| Amir | Saya demam, batuk, dan sakit kepala sejak tiga hari lalu. |
| Jururawat | Baik. Suhu badan encik 38.5 darjah. Sila duduk dan tunggu sebentar. |
| Doktor | Selamat pagi. Encik ada alahan terhadap mana-mana ubat? |
| Amir | Tidak ada, Doktor. |
| Doktor | Baik. Saya akan beri ubat demam dan ubat batuk. Rehat dan minum banyak air. |
| Amir | Terima kasih, Doktor. Berapa lama saya perlu makan ubat ini? |
| Doktor | Tiga kali sehari selama lima hari. Jika tidak sembuh, datang semula. |

### Dialog 2 — Bertanya Khabar Kesihatan

| Penutur | Dialog |
|---|---|
| Hanis | Farid, awak nampak pucat hari ini. Adakah awak sihat? |
| Farid | Saya kurang sihat. Badan saya panas dan kepala saya pening. |
| Hanis | Sudah pergi berjumpa doktor? |
| Farid | Belum lagi. Saya bercadang hendak pergi petang ini. |
| Hanis | Elok awak pergi segera. Minum banyak air dan berehat ya. |
| Farid | Terima kasih atas nasihat awak. |
| Hanis | Semoga cepat sembuh! Jaga diri baik-baik. |

### Contoh Mesej Memohon Cuti Sakit

> *Selamat pagi, Encik Ahmad. Saya tidak dapat datang bekerja hari ini **kerana** saya demam **dan** selesema. Saya mahu pergi ke klinik sekarang. Saya akan menghantar sijil cuti sakit kemudian. Terima kasih.*

**Struktur:** Sapaan + Sebab + Tindakan / Harapan

### Frasa Berguna

| Frasa | Fungsi | Bahasa Thai |
|---|---|---|
| Adakah anda sihat? | Bertanya khabar | คุณสบายดีไหม |
| Saya kurang sihat. | Keadaan tidak sihat | ฉันไม่ค่อยสบาย |
| Saya sakit ... | Bahagian yang sakit | ฉันปวด... |
| Sejak bila awak rasa begitu? | Bertanya tempoh | เป็นตั้งแต่เมื่อไร |
| Semoga cepat sembuh! | Ucapan simpati | ขอให้หายเร็ว ๆ |
| Jaga diri baik-baik. | Nasihat | ดูแลตัวเองด้วย |
| Saya tidak ada selera makan. | Hilang selera | ฉันไม่อยากอาหาร |

## Tatabahasa

### Kata Hubung

| Kata Hubung | Fungsi | Contoh |
|---|---|---|
| **dan** | Gabungan | Saya demam **dan** batuk. |
| **atau** | Pilihan | Awak mahu ubat cecair **atau** pil? |
| **tetapi** | Pertentangan | Saya sakit **tetapi** saya mahu belajar. |
| **kerana** | Sebab | Saya tidak hadir **kerana** saya demam. |

### Ayat Menyatakan Gejala

**Struktur: SUBJEK + PREDIKAT + KETERANGAN**

| Ayat |
|---|
| Saya sakit kepala sejak semalam. |
| Adik demam sejak tiga hari lalu. |
| Pesakit itu rasa pening apabila berdiri. |
| Ibu saya menghidap kencing manis. |

### Kata Tanya Kesihatan

| Kata Tanya | Contoh Soalan | Contoh Jawapan |
|---|---|---|
| Apa | Apa yang awak rasa? | Saya rasa pening dan loya. |
| Di mana | Bahagian mana yang sakit? | Perut saya sakit. |
| Sejak bila | Sejak bila awak demam? | Sejak dua hari lalu. |
| Berapa kali | Berapa kali awak muntah? | Dua kali. |
| Mengapa | Mengapa awak tidak datang? | Kerana saya tidak sihat. |
| Bagaimana | Bagaimana keadaan awak sekarang? | Saya rasa lebih baik. |

### Ayat Nasihat: Perlu, Harus, Jangan

| Kata | Fungsi | Contoh |
|---|---|---|
| perlu | Keperluan | Awak perlu minum lapan gelas air sehari. |
| harus | Kewajipan | Kita harus menjaga kesihatan. |
| sebaiknya | Cadangan | Awak sebaiknya berjumpa doktor segera. |
| jangan | Larangan | Jangan makan makanan berlemak berlebihan. |

## Latihan

### Latihan A — Padankan Gejala dengan Penyakit

| Gejala | Penyakit |
|---|---|
| 1. Badan panas, menggigil, lesu | A. Alahan |
| 2. Hidung tersumbat, bersin, mata berair | B. Demam |
| 3. Sakit perut, cirit-birit, muntah | C. Sakit kepala |
| 4. Kepala berdenyut, mata rasa berat | D. Selesema |
| 5. Kulit gatal, kemerahan, bengkak | E. Keracunan makanan |

### Latihan B — Sambung Ayat dengan Kata Hubung

1. Saya sakit perut ________ (kerana) ...
2. Kepala saya sakit ________ (tetapi) ...
3. Adik demam ________ (dan) ...
4. Awak mahu berehat di rumah ________ (atau) ...
