## Objektif Pembelajaran

Pada akhir sesi, peserta dapat:

- Menggunakan **kata tanya** *Apa, Berapa, Mana,* dan *Bila* dengan intonasi yang betul (nada naik di hujung) dalam situasi jual beli
- Mempraktikkan sekurang-kurangnya **5 ungkapan tawar-menawar** yang sopan dalam BMS
- Menyebut dan menulis sekurang-kurangnya 20 kosa kata perniagaan dengan sebutan BMS yang tepat
- Menyebut kata sifat harga *murah* dan *mahal* dengan sebutan yang jelas
- Menjalankan simulasi tawar-menawar (6–10 ayat) dengan nada yang sopan dan profesional

## Kosa Kata

### Kosa Kata Perniagaan

| Bahasa Melayu | Bahasa Thai | Contoh Ayat |
|---|---|---|
| harga | ราคา | Berapa harga baju ini? |
| murah | ถูก | Buah-buahan di pasar ini sangat murah. |
| mahal | แพง | Emas semakin mahal setiap tahun. |
| diskaun | ส่วนลด | Boleh beri diskaun sedikit? |
| jual | ขาย | Peniaga itu menjual sayur segar setiap pagi. |
| beli | ซื้อ | Saya mahu membeli dua kilo mangga. |
| pelanggan | ลูกค้า | Kedai ini ada ramai pelanggan tetap. |
| peniaga | พ่อค้า / แม่ค้า | Peniaga itu peramah dan suka bertegur sapa. |
| tawar-menawar | การต่อรองราคา | Tawar-menawar ialah budaya biasa di pasar. |
| wang / duit | เงิน | Saya bawa lima ratus baht sahaja. |
| resit | ใบเสร็จ | Boleh saya minta resit? |
| berbaloi | คุ้มค่า | Harga ini berbaloi dengan kualiti barang. |
| sekilo | หนึ่งกิโลกรัม | Sekilo ayam berharga lapan puluh baht. |
| kualiti | คุณภาพ | Kualiti kain ini sangat baik. |
| borong | ขายส่ง | Harga borong lebih murah daripada harga runcit. |

### Ungkapan Tawar-Menawar

| Ungkapan | Bahasa Thai | Fungsi |
|---|---|---|
| Boleh kurang sedikit? | ลดหน่อยได้ไหม | Meminta potongan harga dengan sopan |
| Mahal sangat, boleh beri diskaun? | แพงไปหน่อย ขอส่วนลดได้ไหม | Pendapat + meminta diskaun |
| Kalau beli dua, berapa harganya? | ถ้าซื้อสองอัน ราคาเท่าไหร่ | Bertanya harga pukal |
| Baiklah, boleh. | ตกลง ได้ | Persetujuan peniaga |
| Terima kasih, saya fikir dahulu. | ขอบคุณ ขอคิดดูก่อน | Menolak dengan sopan |
| Terima kasih kerana membeli. | ขอบคุณที่อุดหนุน | Ucapan penutup peniaga |

## Perbualan

### Dialog 1 — Murah dan Mahal

| Penutur | Dialog |
|---|---|
| Guru | Lihat gambar ini. Baju ini murah tetapi kainnya mahal. |
| Aina | Betul, cikgu. Kain sutera memang lebih mahal daripada kain kapas. |
| Guru | Bagus! Sekarang cuba sebut 'murah' dan 'mahal' dengan tegas di hujung. |
| Aina | Murah… mahal. Baju ini murah tetapi kainnya mahal. |

### Dialog 2 — Simulasi "Pasar Terapung"

*Situasi: Pembeli ada bajet 500 baht dan melakukan tawar-menawar dengan peniaga.*

| Penutur | Dialog |
|---|---|
| Pembeli | Selamat petang. Berapa harga mangga ini? |
| Peniaga | Selamat petang. Satu kilo lapan puluh baht. |
| Pembeli | Mahal sangat. Boleh kurang sedikit? |
| Peniaga | Baiklah, tujuh puluh baht sahaja untuk adik. |
| Pembeli | Kalau saya beli dua kilo, boleh beri seratus tiga puluh baht? |
| Peniaga | Baiklah, boleh. Terima kasih kerana membeli. |
| Pembeli | Sama-sama. Boleh saya minta resit? |

## Tatabahasa

### Ayat Tanya dalam Jual Beli

**Ayat tanya BMS diakhiri dengan nada NAIK ↗**

| Kata Tanya | Fungsi | Contoh |
|---|---|---|
| Apa | Jenis / ciri barang | Apa kelebihan kain ini? ↗ |
| Berapa | Harga / kuantiti | Berapa harga sekilo ayam ini? ↗ |
| Mana | Pilihan | Mana satu yang paling bagus? ↗ |
| Bila | Masa | Bila pasar malam ini dibuka? ↗ |
| Siapa | Orang | Siapa yang menjual buah-buahan ini? ↗ |

### Struktur Ayat Tawar-Menawar

| Struktur | Contoh |
|---|---|
| Boleh + Kata Kerja + sedikit? | Boleh kurang sedikit? |
| Kata Sifat + sangat, boleh + Kata Kerja? | Mahal sangat, boleh beri diskaun? |
| Kalau + syarat, berapa + Kata Nama? | Kalau beli dua, berapa harganya? |
| Subjek + Kata Sifat + **tetapi** + Subjek + Kata Sifat | Baju ini murah tetapi kainnya mahal. |

## Latihan

### Latihan A — Padankan Ungkapan dengan Maksud

| Ungkapan | Maksud |
|---|---|
| 1. Boleh kurang sedikit? | A. Bertanya harga pukal |
| 2. Berapa harga sekilo ayam ini? | B. Memohon diskaun |
| 3. Kalau beli dua, berapa harganya? | C. Bertanya harga seunit |
| 4. Baju ini murah tetapi kainnya mahal. | D. Ayat perbandingan |
| 5. Terima kasih kerana membeli. | E. Ucapan penutup peniaga |

### Latihan B — Isi Tempat Kosong

*[ murah · diskaun · berapa · mahal · borong · resit ]*

1. Baju ini sangat ________, tetapi kualitinya bagus.
2. ________ harga sekilo mangga ini, cik?
3. Boleh saya minta ________ sedikit? Harganya ________ sangat.
4. Kalau beli secara ________, harganya lebih murah.
5. Boleh saya minta ________ selepas membayar?

### Latihan C — "Chat-Sale"

Taip satu ayat menggunakan **Berapa** dan **diskaun**. *Contoh: "Berapa harga baju ini selepas diskaun?"*
