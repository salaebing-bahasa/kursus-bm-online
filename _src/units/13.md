## Objektif Pembelajaran

Pada akhir sesi, peserta dapat:

- Menamakan sekurang-kurangnya **15 jenis pakaian** dan **10 warna** dengan sebutan yang betul
- Menggunakan **kata adjektif warna dan ukuran** untuk memerihalkan pakaian (*baju biru, seluar panjang*)
- Membina ayat mengikut **Hukum D-M**: [Kata Nama] + [Warna] + [Saiz / Keadaan]
- Menyebut nama warna dengan sebutan yang jelas, terutama *hijau* (diftong 'au') dan *kuning* (bunyi 'ng')
- Memerihalkan pakaian sendiri dan rakan (5–7 ayat) secara dalam talian

## Perbualan

### Dialog 1 — Apa yang Anda Pakai Hari Ini?

| Penutur | Dialog |
|---|---|
| Guru | Selamat pagi, semua! Razif, apa yang awak pakai hari ini? |
| Razif | Selamat pagi, cikgu. Saya memakai baju biru dan seluar hitam. |
| Guru | Bagus! Nurul, awak pula memakai apa? |
| Nurul | Saya memakai baju kurung hijau dan tudung putih. |
| Guru | Cantiknya! Kenapa awak suka warna hijau? |
| Nurul | Kerana hijau ialah warna kegemaran saya. |
| Guru | Apa warna kasut Razif? |
| Razif | Kasut saya berwarna hitam dan masih baharu. |

### Dialog 2 — Membeli Baju Kurung

| Penutur | Dialog |
|---|---|
| Penjual | Selamat datang! Ada apa yang boleh saya bantu? |
| Aina | Saya mencari baju kurung untuk hari raya. Ada warna apa? |
| Penjual | Kami ada warna merah, biru, hijau, dan ungu. Cik suka warna apa? |
| Aina | Saya suka warna ungu. Boleh saya cuba baju kurung ungu itu? |
| Penjual | Boleh. Cik pakai saiz apa? Kecil, sederhana, atau besar? |
| Aina | Saiz sederhana. Berapa harganya? |
| Penjual | Baju kurung ini seribu dua ratus baht sepasang. |
| Aina | Baiklah, saya beli sepasang baju kurung ungu ini. Terima kasih. |

### Frasa Berguna

| Frasa | Fungsi |
| --- | --- |
| Saya memakai ... hari ini. | Pakaian yang dipakai |
| ... saya berwarna ... | Warna pakaian |
| Warna kegemaran saya ialah ... | Warna kegemaran |
| Apa warna ... awak? | Bertanya warna |
| ... ini terlalu besar / kecil. | Saiz |

## Tatabahasa

### Hukum D-M (Diterangkan – Menerangkan)

Dalam Bahasa Melayu, **kata nama (D)** datang **dahulu**, kemudian **warna / sifat (M)**.

| Kata Nama (D) | Warna (M) | ✓ Betul | ✗ Salah |
|---|---|---|---|
| baju | merah | **baju merah** | merah baju |
| seluar | hitam | **seluar hitam** | hitam seluar |
| tudung | ungu | **tudung ungu** | ungu tudung |
| kasut | putih | **kasut putih** | putih kasut |

### Ayat Deskriptif

**[Kata Nama] + [Warna] + [Saiz / Keadaan]**

| Ayat |
|---|
| Baju biru itu besar. |
| Kemeja putih itu baharu. |
| Seluar hitam itu ketat. |
| Baju kurung ungu itu selesa dipakai. |

## Latihan

### Latihan A — Namakan Pakaian

1. Pakaian tradisional wanita Melayu → ________
2. Dipakai di kepala oleh wanita Muslim → ________
3. Dipakai di kaki sebelum memakai kasut → ________
4. Dipakai lelaki di kepala ke masjid → ________

### Latihan B — Warna

1. Daun pokok biasanya berwarna ________.
2. Langit yang cerah pada waktu siang berwarna ________.
3. Awan biasanya berwarna ________.
4. Malam yang gelap berwarna ________.

### Latihan C — Susun Mengikut Hukum D-M

1. merah / saya / baju / memakai
2. itu / hijau / cantik / tudung
3. baharu / kasut / putih / saya

### Latihan D — "Fesyen Kegemaran Saya"

Sediakan 2–3 slaid dan bentangkan pakaian kegemaran anda. *Contoh: "Saya memakai kemeja coklat dan seluar hitam."*
