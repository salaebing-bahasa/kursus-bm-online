## Objektif Pembelajaran

Pada akhir sesi, peserta dapat:

- Menyebut dan menulis sekurang-kurangnya **20 kosa kata** perjalanan dan pelancongan
- Menggunakan **kata tanya** *Bagaimana, Mengapa, Di mana, Berapa* untuk mendapatkan maklumat perjalanan
- Menggunakan **kata bantu masa** (*sudah, sedang, akan, baru sahaja*) untuk rancangan perjalanan
- Memberi cadangan dan nasihat dengan sopan kepada pelancong
- Merancang **itinerari ringkas** ke Malaysia atau Indonesia

## Kosa Kata

|---|---|---|

## Perbualan

### Dialog 1 — Di Kaunter Imigresen

| Penutur | Dialog |
|---|---|
| Pegawai | Selamat pagi. Boleh saya lihat pasport anda? |
| Pelancong | Ya, ini pasport saya. |
| Pegawai | Bagaimana anda datang ke sini? Naik bas atau kapal terbang? |
| Pelancong | Saya datang dengan kapal terbang. |
| Pegawai | Mengapa anda datang ke Malaysia? |
| Pelancong | Saya datang untuk melancong dan melawat kawan. |
| Pegawai | Berapa lama anda mahu tinggal di sini? |
| Pelancong | Saya mahu tinggal selama lima hari. |
| Pegawai | Baik. Selamat datang ke Malaysia! |

### Dialog 2 — Di Kaunter Daftar Masuk

| Penutur | Dialog |
|---|---|
| Petugas | Selamat pagi. Boleh saya lihat pasport dan tiket anda? |
| Zara | Selamat pagi. Ini pasport dan tiket saya. Saya ke Kuala Lumpur. |
| Petugas | Berapa beg bagasi yang anda mahu daftarkan? |
| Zara | Satu beg sahaja. |
| Petugas | Baiklah. Ini pas naik anda. Penerbangan akan berlepas dari pintu 12. |
| Zara | Terima kasih atas bantuan anda. |

### Dialog 3 — Meminta Cadangan

| Penutur | Dialog |
|---|---|
| Sofia | Maaf, boleh saya bertanya? Di mana pusat pelancongan yang berhampiran? |
| Pak Man | Tidak jauh dari sini, lima minit berjalan kaki. |
| Sofia | Boleh Pak Man cadangkan tempat menarik untuk dilawati? |
| Pak Man | Saya cadangkan awak melawat muzium lama dan pantai berhampiran. |
| Sofia | Bagaimana pula dengan makanan tempatan? |
| Pak Man | Sebaiknya awak cuba restoran di hujung jalan ini. Makanan lautnya terkenal. |
| Sofia | Terima kasih atas cadangan Pak Man! |

## Tatabahasa

### Kata Tanya untuk Melancong

| Kata Tanya | Contoh | Bahasa Thai |
|---|---|---|
| Bagaimana | Bagaimana saya hendak ke Kuala Lumpur? | จะไปกัวลาลัมเปอร์อย่างไร |
| Mengapa | Mengapa penerbangan ini lewat? | ทำไมเที่ยวบินนี้ล่าช้า |
| Di mana | Di mana saya boleh menukar wang? | แลกเงินได้ที่ไหน |
| Berapa | Berapa harga tiket ke Jakarta? | ตั๋วไปจาการ์ตาราคาเท่าไหร่ |
| Bila | Bila bas akan bertolak? | รถบัสจะออกเมื่อไร |
| Pukul berapa | Pukul berapa penerbangan kita berlepas? | เที่ยวบินออกกี่โมง |

### Kata Bantu Masa

| Kata | Contoh | Bahasa Thai |
|---|---|---|
| sudah | Saya sudah menempah bilik hotel. | ฉันจองห้องแล้ว |
| sedang | Kami sedang melancong di Pulau Pinang. | เรากำลังเที่ยวที่ปีนัง |
| akan | Kami akan melancong ke Jakarta bulan depan. | เราจะไปจาการ์ตาเดือนหน้า |
| baru sahaja | Kami baru sahaja mendarat. | เราเพิ่งลงจอด |

### Ayat Cadangan dan Nasihat

| Struktur | Contoh |
|---|---|
| Saya cadangkan ... | Saya cadangkan anda melawat muzium itu. |
| Sebaiknya ... | Sebaiknya anda membawa payung. |
| Anda patut ... | Anda patut menempah tiket lebih awal. |
| Jangan lupa ... | Jangan lupa membawa pasport. |

## Latihan

### Latihan A — Padankan

| Istilah | Tempat |

| 1. imigresen | A. muzium |
| 2. menukar wang | B. lapangan terbang |
| 3. mendaki | C. bank |
| 4. artifak sejarah | D. gunung |

### Latihan B — Kata Bantu Masa

*[ sudah · sedang · akan · baru sahaja ]*

1. Kami ________ menempah tiket kapal terbang minggu lepas.
2. Saya ________ melancong di Melaka sekarang.
3. Kami ________ ke Jakarta bulan depan.
4. Kami ________ mendarat di lapangan terbang.

### Latihan C — Itinerari Pelancongan

Rancang perjalanan 3 hari ke Malaysia atau Indonesia. Untuk setiap hari, tulis 2–3 ayat menggunakan kata bantu masa dan kata tanya.
