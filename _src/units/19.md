## Objektif Pembelajaran

Pada akhir sesi, peserta dapat:

- Mengenal pasti **isi penting dan mesej utama** daripada video atau cerita pendek dalam BMS
- Memberi pendapat menggunakan **kata adjektif penilaian** (*menarik, membosankan, menyentuh hati*)
- **Membina perenggan mudah** (5–8 ayat): ringkasan + pendapat + pengajaran
- Menulis **ulasan pendek tentang filem Melayu**
- Mengulang kaji kosa kata dan tatabahasa utama sepanjang kursus

## Kosa Kata

### Istilah Ulasan

| Bahasa Melayu | Bahasa Thai | Contoh Ayat |
|---|---|---|
| ulasan | บทวิจารณ์ | Saya menulis ulasan tentang filem itu. |
| watak | ตัวละคร | Watak utama filem ini sangat berani. |
| plot / jalan cerita | โครงเรื่อง | Jalan cerita filem itu mudah difahami. |
| latar | ฉาก (สถานที่/เวลา) | Latar cerita ini ialah sebuah kampung di Patani. |
| pengajaran | ข้อคิด / บทเรียน | Pengajaran cerita ini ialah kita mesti menghormati ibu bapa. |
| mesej | สาร / ข้อความสำคัญ | Mesej filem itu sangat jelas. |
| penonton | ผู้ชม | Filem itu disukai ramai penonton. |
| pendapat | ความคิดเห็น | Pada pendapat saya, filem ini sangat baik. |

| hebat | ยอดเยี่ยม | mengelirukan | ทำให้สับสน |
| bermanfaat | มีประโยชน์ | terlalu panjang | ยาวเกินไป |

## Perbualan

### Dialog 1 — Bintang Penarafan

| Penutur | Dialog |
|---|---|
| Guru | Siapa sudah menonton filem animasi Melayu? Berapa bintang anda berikan? |
| Farah | Saya beri lima bintang, cikgu. |
| Guru | Mengapa? |
| Farah | Kerana jalan ceritanya sangat menarik dan wataknya lucu. |
| Amir | Saya pula beri empat bintang. Filem itu bermanfaat, tetapi agak panjang. |
| Guru | Bagus! Anda berdua memberi pendapat dengan alasan yang jelas. |

### Dialog 2 — Refleksi Pembelajaran

| Penutur | Dialog |
|---|---|
| Cikgu Salmah | Sebelum kursus ini tamat, apakah yang paling anda ingat? |
| Farah | Saya paling ingat cara memberi arah, seperti "belok kanan" dan "jalan terus". |
| Amir | Saya pula ingat kosa kata cuaca, terutamanya musim tengkujuh. |
| Cikgu Salmah | Adakah tatabahasa yang masih sukar? |
| Farah | Darjah perbandingan seperti "lebih ... daripada" kadang-kadang mengelirukan. |
| Cikgu Salmah | Tidak mengapa, kita akan mengulang kaji bersama-sama hari ini. |

## Tatabahasa

### Membina Perenggan Ulasan Mudah

**Aliran: Ringkasan → Pendapat → Pengajaran**

| Ayat | Templat | Contoh |
|---|---|---|
| 1 | Tajuk video / filem ini ialah ... | Tajuk filem ini ialah *Kampung Kita*. |
| 2 | Ia menceritakan tentang ... | Ia menceritakan tentang seorang budak yang rajin membantu ibunya. |
| 3 | Watak utamanya ialah ... | Watak utamanya ialah Ali, seorang murid sekolah rendah. |
| 4 | Pada pendapat saya, ... sangat ... kerana ... | Pada pendapat saya, filem ini sangat menyentuh hati kerana jalan ceritanya realistik. |
| 5 | Pengajaran yang saya dapat ialah ... | Pengajaran yang saya dapat ialah kita mesti menyayangi keluarga. |

### Kata Hubung dalam Ayat Kompleks

| Kata Hubung | Contoh |
|---|---|
| kerana | Saya suka filem ini **kerana** wataknya lucu. |
| supaya | Tonton filem ini **supaya** anda faham budaya Melayu. |
| walaupun | **Walaupun** filem itu panjang, jalan ceritanya menarik. |

### Ulang Kaji Tatabahasa Kursus

| Topik | Contoh |
|---|---|
| Imbuhan ber- | Kami **berkumpul** bersama keluarga setiap tahun. |
| Imbuhan meN- | Guru itu **mengajar** dengan penuh sabar. |
| Kata bantu masa | Saya **sudah** menempah, **sedang** berkemas, dan **akan** berlepas esok. |
| Kekerapan | Saya **selalu** membaca berita pada waktu pagi. |
| Darjah perbandingan | Hari ini **lebih** panas **daripada** semalam. |
| Penanda wacana | **Mula-mula** ..., **kemudian** ..., **akhirnya** ... |

## Latihan

### Latihan A — Tonton & Catat

Tonton video pendek (2–3 minit). Catat: **Siapa watak utama? Apa yang berlaku? Apa pengajarannya?**

### Latihan B — Kotak Adjektif

Padankan: cerita hantu · cerita ibu bapa · cerita jenaka · video tutorial → *menakutkan · menyentuh hati · lucu · bermanfaat*

### Latihan C — Isi Tempat Kosong (Ulang Kaji)

*[ kerana · lebih · akan · selalu · mengajar ]*

1. Guru itu ________ dengan penuh sabar.
2. Hari ini ________ panas daripada semalam.
3. Kami ________ melancong ke luar negara setiap tahun.
4. Penerbangan ditunda ________ cuaca buruk.
5. Kami ________ ke Jakarta bulan depan.

### Latihan D — Ulasan Filem Melayu

Tulis ulasan pendek (5–8 ayat) tentang sebuah filem atau drama Melayu yang pernah anda tonton menggunakan templat di atas.
