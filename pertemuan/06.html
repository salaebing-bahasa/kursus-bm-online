Objektif Pembelajaran

Pada akhir sesi, peserta dapat:

  • Menyebut dan menulis sekurang-kurangnya 25 kosa kata bilik, perabot, dan persekitaran rumah
  • Menghuraikan lokasi objek dengan kata sendi nama tempat: di atas, di bawah, di dalam, di luar, di sebelah, di hadapan, di belakang
  • Menggunakan kata adjektif (bersih, luas, selesa, cantik) untuk memerihalkan rumah
  • Menjalankan perbualan pendek (4–6 ayat) tentang rumah dengan rakan
  • Menulis sekurang-kurangnya 4 ayat menghuraikan rumah sendiri

Kata Sendi Nama Tempat

Kata Sendi Bahasa Thai Contoh Ayat
di atas บน Lampu tergantung di atas meja makan.
di bawah ใต้ Kasut disimpan di bawah katil.
di dalam ข้างใน Baju ada di dalam almari.
di luar ข้างนอก Kereta diletakkan di luar garaj.
di sebelah ข้าง ๆ Kerusi ada di sebelah meja.
di hadapan ข้างหน้า Televisyen ada di hadapan sofa.
di belakang ข้างหลัง Taman bunga ada di belakang rumah.
di antara ระหว่าง Dapur ada di antara bilik makan dan bilik utiliti.

Perbualan

Dialog 1 — Rumah Saya

Razman

Assalamualaikum, Sara. Awak tinggal di mana?

Sara

Waalaikumsalam. Saya tinggal di Songkhla, dalam sebuah rumah teres dua tingkat. Awak pula?

Razman

Saya tinggal di pangsapuri di bandar. Rumah awak ada berapa bilik?

Sara

Rumah saya ada tiga bilik tidur, dua bilik air, sebuah dapur, dan sebuah ruang tamu.

Razman

Wah, besarnya! Di mana bilik awak?

Sara

Bilik saya di tingkat atas, di sebelah bilik ibu bapa saya. Ada tingkap besar menghadap taman.

Razman

Perabot apa yang ada di bilik awak?

Sara

Ada katil, almari, meja belajar, dan penghawa dingin. Saya suka bilik saya kerana selesa.

Dialog 2 — Melawat Rumah Baharu

Hakim

Nadia, saya baru berpindah ke rumah baharu minggu lepas. Mahu datang melawat?

Nadia

Oh, bagus! Rumah baharu di mana?

Hakim

Di Taman Sri Damai, tidak jauh dari sekolah. Lebih kurang lima minit sahaja.

Nadia

Jenis rumah apa? Rumah teres atau banglo?

Hakim

Rumah banglo. Ada halaman depan dan belakang. Di halaman belakang ada pokok buah-buahan.

Nadia

Cantiknya! Bila boleh saya datang?

Hakim

Sabtu ini boleh. Saya akan tunjukkan semua bilik dan halaman.

Nadia

Baiklah! Saya akan datang pukul sepuluh pagi. Terima kasih atas jemputan!

Tatabahasa

Ayat Lokasi

Struktur: SUBJEK + ada / terletak / berada + KATA SENDI NAMA + TEMPAT

Subjek Kata Kerja Kata Sendi Tempat Ayat
Buku ada di atas meja Buku ada di atas meja.
Katil berada di dalam bilik tidur Katil berada di dalam bilik tidur.
Televisyen ada di hadapan sofa Televisyen ada di hadapan sofa.
Taman terletak di belakang rumah Taman terletak di belakang rumah.

Ada, Mempunyai, Terdapat

Kata Penggunaan Contoh
ada Kewujudan (มี / อยู่) Di ruang tamu ada sofa besar.
mempunyai Pemilikan (มี — เป็นเจ้าของ) Rumah saya mempunyai tiga bilik tidur.
terdapat Formal (มี — ทางการ) Terdapat sebuah taman di belakang rumah.

Kata Adjektif untuk Rumah

Struktur: [Subjek] + [Kata Adjektif] → Bilik saya selesa.

Kata Adjektif Bahasa Thai Contoh
besar / kecil ใหญ่ / เล็ก Bilik saya kecil tetapi selesa.
luas / sempit กว้าง / แคบ Ruang tamu kami sangat luas.
selesa สะดวกสบาย Katil saya sangat selesa.
bersih สะอาด Dapur rumah saya sangat bersih.
kemas เป็นระเบียบ Bilik adik saya sentiasa kemas.
baharu / lama ใหม่ / เก่า Rumah nenek sudah lama tetapi kukuh.
cantik สวย Taman di luar rumah itu cantik.
jauh / dekat ไกล / ใกล้ Rumah saya dekat dengan sekolah.

Penjodoh Bilangan dalam Konteks Rumah

Penjodoh Contoh

tingkat Rumah kami ada dua tingkat.
