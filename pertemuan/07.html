Objektif Pembelajaranวัตถุประสงค์

Pada akhir sesi, peserta dapat:

  • Menyebut dan menulis sekurang-kurangnya 25 kosa kata rutin harian dengan sebutan yang tepat
  • Menyatakan masa dengan betul (pagi, tengah hari, petang, malam)
  • Membina ayat Subjek + Kata Kerja + Objek (Saya makan nasi.)
  • Menyusun urutan aktiviti dengan penanda wacana: mula-mula, kemudian, selepas itu, akhir sekali
  • Menulis satu perenggan (5 ayat) tentang rutin harian sendiri

Waktu

sejam หนึ่งชั่วโมง Dia belajar selama sejam setiap malam.

Perbualanบทสนทนา

Dialog 1 — Rutin Harian

Farid

Assalamualaikum, Hana! Apa khabar hari ini?

Hana

Waalaikumsalam! Khabar baik, alhamdulillah. Farid, pukul berapa awak bangun tidur setiap hari?

Farid

Saya biasanya bangun pada pukul lima setengah pagi. Kemudian saya bersolat subuh.

Hana

Wah, awal sekali! Saya bangun pukul enam. Selepas mandi, saya bersarapan bersama keluarga.

Farid

Pukul berapa awak pergi ke kelas?

Hana

Kelas dalam talian saya bermula pukul lapan pagi dan berakhir pukul dua belas tengah hari.

Farid

Selepas kelas, apa yang awak buat?

Hana

Saya makan tengah hari, kemudian berehat sebentar. Pada waktu petang, saya bersenam.

Farid

Malam pula?

Hana

Pada waktu malam saya mengulang kaji selama sejam, menonton televisyen, dan tidur sebelum pukul sebelas.

Dialog 2 — Hari Bekerja dan Hujung Minggu

Guru

Rashid, adakah rutin harian awak pada hari bekerja berbeza dengan hujung minggu?

Rashid

Ya, cikgu. Pada hari bekerja, saya bangun pukul enam pagi. Pada hujung minggu, saya bangun lewat sedikit, kira-kira pukul tujuh.

Guru

Apa yang awak buat pada hujung minggu?

Rashid

Saya membantu ibu membersihkan rumah. Selepas itu, kami sekeluarga pergi membeli-belah atau berjalan-jalan di taman.

Guru

Bagus! Awak pandai menguruskan masa.

Tatabahasaไวยากรณ์

Struktur Ayat Asas

Struktur Contoh
Subjek + Kata Kerja Saya mandi.
Subjek + Kata Kerja + Objek Saya makan nasi.
Subjek + Kata Kerja + Keterangan Masa Saya bangun pada pukul enam pagi.

Kata Kerja Transitif

Kata kerja transitif memerlukan objek selepasnya.

Ayat Kata Kerja Objek
Ibu memasak sarapan. memasak sarapan
Saya membaca buku. membaca buku
Dia menggosok gigi. menggosok gigi
Kami menonton televisyen. menonton televisyen

Latihanแบบฝึกหัด

Latihan A — Padankan Aktiviti dengan Waktu

Aktiviti Waktu
1. menggosok gigi dan mandi A. 10:00 malam
2. makan tengah hari B. 6:00 pagi
3. mengulang kaji pelajaran C. 12:30 tengah hari
4. bangun tidur D. 8:00 malam
5. tidur E. 6:30 pagi

Latihan B — Lengkapkan Ayat

[ kemudian · selepas · sebelum · biasanya · pada pukul · selama ]

  1. Saya bangun tidur __ enam pagi setiap hari.
  2. __ mandi, saya bersarapan bersama keluarga.
  3. Dia __ tidur awal, sekitar pukul sepuluh malam.
  4. Ibu memasak sarapan, __ menghantar adik ke sekolah.
  5. Saya bersenam __ tiga puluh minit setiap petang.
  6. Saya menggosok gigi __ tidur.

Latihan C — Rantai Rutin

Sambung ayat rakan: "Mula-mula, saya bangun tidur." → "Kemudian, saya ..." → "Selepas itu, saya ..."
