Objektif Pembelajaran

Pada akhir sesi, peserta dapat:

  • Menyebut dan menulis sekurang-kurangnya 20 kosa kata hobi dan minat dengan tepat
  • Bertanya dan menjawab tentang hobi dengan kata tanya Apa, Berapa kali, dan Mengapa
  • Membezakan kata kerja tak transitif (berenang) dan transitif (membaca buku)
  • Menggunakan kata penguat sangat, paling, dan gemar dalam ayat tentang minat
  • Menjalankan perbualan pendek (3–5 ayat) dan menulis 3 ayat tentang hobi sendiri

Perbualan

Dialog 1 — Apa Hobi Awak?

Ahmad

Assalamualaikum, Siti. Apa khabar?

Siti

Waalaikumsalam. Khabar baik, terima kasih. Ahmad, apa hobi awak?

Ahmad

Hobi saya ialah membaca buku dan menonton filem. Awak pula?

Siti

Saya suka memasak dan mengambil gambar. Mengapa awak suka membaca?

Ahmad

Kerana membaca boleh menambah ilmu pengetahuan. Lagipun, ia sangat menarik!

Siti

Betul! Berapa kali awak membaca dalam seminggu?

Ahmad

Saya membaca setiap hari, lebih kurang satu jam.

Siti

Wah, rajinnya! Saya pun mahu cuba membaca dengan kerap.

Dialog 2 — Hobi pada Hujung Minggu

Razif

Laila, apa yang awak biasanya buat pada hujung minggu?

Laila

Saya suka berkebun dan menjahit. Kadang-kadang saya menonton filem bersama keluarga. Awak pula?

Razif

Saya suka bermain badminton dan memancing. Sukan membuatkan badan saya lebih sihat.

Laila

Bilakah awak biasanya bermain badminton?

Razif

Setiap Sabtu pagi, pukul tujuh hingga sembilan. Awak mahu cuba?

Laila

Boleh juga! Saya berminat untuk mencuba.

Frasa Berguna

Frasa Fungsi Bahasa Thai
Hobi saya ialah ... Menyatakan hobi งานอดิเรกของฉันคือ...
Saya suka / gemar ... Menyatakan kesukaan ฉันชอบ...
Saya tidak suka ... Ketidaksukaan ฉันไม่ชอบ...
Apakah hobi awak pada masa lapang? Bertanya hobi ยามว่างคุณชอบทำอะไร
Mengapa awak suka ...? Bertanya sebab ทำไมคุณถึงชอบ...
Berapa kali awak ... dalam seminggu? Bertanya kekerapan คุณ...สัปดาห์ละกี่ครั้ง
Saya berminat untuk ... Menyatakan minat ฉันสนใจที่จะ...

Nota Dialek → Standard: "Saya hobi..." → "Hobi saya ialah..." atau "Saya gemar...". Gunakan "Hobi saya ialah...", bukan "Hobi saya adalah...".

Tatabahasa

Kata Kerja Tak Transitif dan Transitif

Jenis Ciri Contoh
Tak transitif Ayat lengkap tanpa objek Saya berenang. Adik menari.
Transitif Perlu objek selepas kata kerja Saya membaca buku. Ibu memasak nasi.

Ayat Aktif dengan Kata Kerja Hobi

Struktur: SUBJEK + KATA KERJA + OBJEK / KETERANGAN

Subjek Kata Kerja Objek / Keterangan Ayat
Saya membaca buku setiap malam Saya membaca buku setiap malam.
Dia melukis pemandangan alam Dia melukis pemandangan alam.
Kami bermain badminton di padang Kami bermain badminton di padang.
Mereka menonton filem di pawagam Mereka menonton filem di pawagam.

Kata Tanya

Kata Tanya Contoh Soalan Contoh Jawapan
Apa Apa hobi awak? Hobi saya ialah membaca.
Siapa Siapa yang suka memancing? Ayah saya suka memancing.
Di mana Di mana awak bermain badminton? Di gelanggang sekolah.
Bilakah Bilakah awak berlatih menari? Setiap Rabu petang.
Berapa kali Berapa kali awak berenang seminggu? Dua kali seminggu.
Mengapa Mengapa awak suka melukis? Kerana ia menenangkan fikiran.

Suka, Gemar, Berminat + Kata Penguat

Kata Bahasa Thai Contoh
suka ชอบ Saya sangat suka berenang.
gemar ชื่นชอบ Dia paling gemar melancong.
berminat สนใจ Saya berminat untuk belajar piano.
tidak suka ไม่ชอบ Saya tidak suka aktiviti yang membosankan.

Latihan

Latihan A — Lengkapkan Ayat

[ suka · hobi · gemar · bermain · setiap · berminat ]

  1. __ saya ialah membaca novel.
  2. Dia __ melukis pemandangan alam semula jadi.
  3. Saya __ untuk belajar bermain piano tahun depan.
  4. Mereka __ badminton di gelanggang pada waktu petang.
  5. Nenek saya __ berkebun __ pagi.

Latihan B — Susun Ayat

  1. suka / buku / membaca / Saya / setiap / malam
  2. mendaki / gunung / Mereka / gemar / pada / hujung / minggu
  3. kali / Berapa / berenang / awak / seminggu?

Latihan C — Temu Bual Rakan

Tanya rakan: Apakah hobi awak pada masa lapang? Mengapa? Berapa kali seminggu? Dengan siapa?
