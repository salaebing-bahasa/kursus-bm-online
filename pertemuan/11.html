Objektif Pembelajaranวัตถุประสงค์

Pada akhir sesi, peserta dapat:

  • Menyebut dan menulis sekurang-kurangnya 25 kosa kata kesihatan diri dan anggota badan
  • Menghuraikan gejala penyakit biasa dengan ayat yang gramatis
  • Menggunakan kata hubung (dan, atau, tetapi, kerana) untuk membina ayat yang lebih panjang
  • Membina dialog antara pesakit dan doktor dengan sopan
  • Menulis mesej ringkas kepada majikan / guru untuk memohon cuti sakit

Perbualanบทสนทนา

Dialog 1 — Di Klinik

Jururawat

Selamat pagi. Ada apa yang boleh saya bantu?

Amir

Selamat pagi. Saya ingin berjumpa doktor. Saya rasa kurang sihat.

Jururawat

Apa masalah encik?

Amir

Saya demam, batuk, dan sakit kepala sejak tiga hari lalu.

Jururawat

Baik. Suhu badan encik 38.5 darjah. Sila duduk dan tunggu sebentar.

Doktor

Selamat pagi. Encik ada alahan terhadap mana-mana ubat?

Amir

Tidak ada, Doktor.

Doktor

Baik. Saya akan beri ubat demam dan ubat batuk. Rehat dan minum banyak air.

Amir

Terima kasih, Doktor. Berapa lama saya perlu makan ubat ini?

Doktor

Tiga kali sehari selama lima hari. Jika tidak sembuh, datang semula.

Dialog 2 — Bertanya Khabar Kesihatan

Hanis

Farid, awak nampak pucat hari ini. Adakah awak sihat?

Farid

Saya kurang sihat. Badan saya panas dan kepala saya pening.

Hanis

Sudah pergi berjumpa doktor?

Farid

Belum lagi. Saya bercadang hendak pergi petang ini.

Hanis

Elok awak pergi segera. Minum banyak air dan berehat ya.

Farid

Terima kasih atas nasihat awak.

Hanis

Semoga cepat sembuh! Jaga diri baik-baik.

Contoh Mesej Memohon Cuti Sakit

Selamat pagi, Encik Ahmad. Saya tidak dapat datang bekerja hari ini kerana saya demam dan selesema. Saya mahu pergi ke klinik sekarang. Saya akan menghantar sijil cuti sakit kemudian. Terima kasih.

Struktur: Sapaan + Sebab + Tindakan / Harapan

Latihanแบบฝึกหัด

Latihan A — Padankan Gejala dengan Penyakit

Gejala Penyakit
1. Badan panas, menggigil, lesu A. Alahan
2. Hidung tersumbat, bersin, mata berair B. Demam
3. Sakit perut, cirit-birit, muntah C. Sakit kepala
4. Kepala berdenyut, mata rasa berat D. Selesema
5. Kulit gatal, kemerahan, bengkak E. Keracunan makanan

Latihan B — Sambung Ayat dengan Kata Hubung

  1. Saya sakit perut __ (kerana) ...
  2. Kepala saya sakit __ (tetapi) ...
  3. Adik demam __ (dan) ...
  4. Awak mahu berehat di rumah __ (atau) ...

Latihan C — Mesej kepada Majikan / Guru

Tulis mesej WhatsApp memohon cuti sakit (3–4 ayat). Gunakan sekurang-kurangnya dua kata hubung.
